# iwamad-sis1-portfolio

Live site: https://abendii12.github.io/iwamad-sis1-portfolio/

## About the site

The site displays my portfolio, containing information about skills, projects and contact information. Website includes dark mode button and contact section where people can leave their name, email and messages. This site is useful for me as it can be used as cv where I could contain information about my skills and projects I worked on.

## Design decisions

1. I made two different interfaces for mobile and computer version, with two different width, mobile version shows project cards in one column not row because the screen is small and it allows to see text and card better when it is in one column and left side avatar photo allows to see information as you opened it 
2. The website main page is light by default, however I made dark mode button so that those who prefer dark interface can change it, I used dark blue color as the main color,my profile portfolio displays hierachy, contrast of text and because of that all text is visible in both versions.
3. After checking the first version, I changed avatar shape from oval to circle because it is more usual to see and it better aligns with text
